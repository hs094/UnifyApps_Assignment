# KGP-Assist Project

This repository contains documentation for the KGP-Assist project, an assignment for UnifyApps.

## Project Overview

KGP-Assist is a project focused on providing assistance services for the IIT Kharagpur community. The project aims to streamline various processes and enhance the user experience for students, faculty, and staff.

## Documentation

The following documentation is available in this repository:

- **KGP-Assist-Presentation.pdf**: Presentation slides for the KGP-Assist project
- **UnifyApps_Assignment_Documentation.pdf**: Detailed documentation of the project requirements and specifications
- **UnifyApps_Assignment_Wireframe.pdf**: Wireframes and UI/UX designs for the application
